# 🚀 DEPLOY RÁPIDO - 5 MINUTOS

## VOCÊ TEM 23 ARQUIVOS PRONTOS

Todos estão em `/mnt/user-data/outputs/`

**Fazer download de TODOS os 23 arquivos** (vai usar os arquivos que vê no outputs)

## PASSO 1️⃣: GITHUB (1 minuto)

```
1. https://github.com/ → Sign up ou Log in
2. Clique "+" → "New repository"
3. Nome: artblend-plataforma
4. Type: Public
5. "Create repository"
```

## PASSO 2️⃣: UPLOAD DOS ARQUIVOS (2 minutos)

Na página do repositório novo:

```
1. Clique "Add file" → "Upload files"
2. Arraste TODOS os 23 arquivos (ou selecione)
3. Scroll até embaixo → "Commit changes"
4. Pronto!
```

## PASSO 3️⃣: NETLIFY (2 minutos)

```
1. https://www.netlify.com/ → Sign up ou Log in
2. "New site from Git"
3. "GitHub" → "Authorize"
4. Busque: artblend-plataforma
5. Deploy settings (deixa padrão):
   - Branch: main
   - Build command: (vazio)
   - Publish: / (raiz)
6. "Deploy site"
```

## PASSO 4️⃣: ESPERAR (1-2 minutos)

Pronto! Site está no ar em:
```
https://XXXX.netlify.app/
```
